# 其他国家和地区：设置时当场调研

不要凭记忆写死平台和签证规定，它们会变。设置时按下面的步骤用网页搜索查，结果写进 criteria.md 的地区小节和 answers.md，每条附来源链接和查询日期，最后请用户确认。

## 要查清楚的五件事
1. **身份和工作许可**：用户在这个地区的身份（学生签证、毕业生签证、公民等）能不能做实习，学期内和假期分别有什么工时限制，雇主要不要办手续。只用政府官网或学校国际学生办公室的页面作为来源。
2. **学生找实习的主要平台**：本地最常用的 3 到 5 个（综合招聘网站、学生实习平台、学校就业系统），以及用户学校的就业中心有没有岗位库、邮件列表或群组。
3. **招聘时间表**：暑期实习一般什么时候开放和截止，有没有寒假或 off-cycle 实习。
4. **申请习惯**：要不要求职信，简历是否一页，是否常见在线测评或视频面试。
5. **常见的身份限制写法**：岗位里表示“只招本地人”或“需要工作权”的常见说法，用来做第 3 道门槛。

## 写进文件的格式
在 criteria.md 的“地区说明”下加一个小节：

```
### <地区>（调研于 YYYY-MM-DD）
* 身份：……（来源：链接）
* 平台顺序：1. …… 2. …… 3. ……
* 招聘时间：……（来源：链接）
* 注意：……
```

answers.md 的“工作许可”下写这个地区的标准答法。

## 找不到可靠来源时
直接告诉用户查不到，请用户去学校国际学生办公室确认，确认前遇到相关表单问题一律停下来问。
