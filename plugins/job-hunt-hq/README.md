# 求职指挥部 job-hunt-hq

一个 Claude 桌面端插件。装好以后说一句“开始设置”，Claude 会问你十几个问题，然后自己搭好一整套实习求职系统：每天找岗位、筛选打分、写求职信和表单回答、在你的浏览器里填表、给没有公开招聘的公司写冷邮件、准备面试。所有提交和发信默认都要你点头。

这套流程来自作者自己四周的真实求职：看了 300 多个岗位，发出 160 多份申请和冷邮件，从中总结出的规则都写进了默认设置里。

## 适合谁
* 找实习的大学生，在国内或海外读书都可以，目标地区可以是中国内地、新加坡或其他国家。
* 求职材料中英文都支持。新加坡和中国内地有详细的平台和经验说明；其他地区在设置时由 Claude 当场调研。

## 需要准备
1. **Claude 桌面端**，账号能使用项目、技能（插件）和定时任务。
2. **Claude in Chrome 扩展**，并在那个 Chrome 里登录你的邮箱、学校就业平台、LinkedIn、实习僧等你会用的招聘网站。
3. **简历**（PDF 或 Word，几个版本都可以）。有成绩单更好。
4. 电脑上一个空文件夹，比如“文稿/Job Hunt HQ”。

## 安装
**方法一：在 Claude 里输入名字（推荐，不用下载）**
1. Claude 桌面端左侧栏打开 **Customize → Plugins → Add marketplace**。
2. 输入 `wangheyueyang-lab/job-hunt-hq`，然后在列表里安装 job-hunt-hq。
3. 以后作者更新，点 **Check for updates** 就能拿到新版本。

**方法二：上传文件**
1. 下载 `job-hunt-hq.plugin`。
2. Claude 桌面端左侧栏打开 **Customize → Plugins**，选择上传，选中这个文件。

## 开始
1. 在 Claude 桌面端新建一个项目，选“使用已有文件夹”，选中你准备好的空文件夹。
2. 在这个项目里说：**开始设置**。
3. 按提示上传简历、回答问题。大约 20 分钟后，你会拿到第一份 10 个岗位的候选名单。

## 每天怎么用
* 打开当天的清单，回复编号：“submit 1, 2, 4”“send 1, 3”“skip 5，太偏销售”。
* 想改方向直接说：“这周只看咨询”“以后不要投银行”。Claude 会把你的每一句“以后都……”写进规则，之后每天照做。
* 收到面试邀请：“帮我准备 XX 的面试”。

## 你始终掌握的事
* Claude 不输入密码、不替你注册账号、不做验证码和在线测评。
* 邮件和平台消息只发你点名批准的。
* 提交申请有三档：每份都问（默认）、短表单直接交、准备好的都直接交。档位只有你能改。
* 所有经历和数字只来自你的简历和你确认过的内容。想让表达更有力时，Claude 会先给你看改前改后。

## 局限
* 定时任务运行时，电脑、Claude 桌面端和 Chrome 要开着。电脑睡着时它读不到文件夹。
* 无人值守时，点击“提交”可能被系统的安全检查拦下。这种情况下材料会准备好，等你在线时一句话就能交。
* 很多大公司的招聘系统要单独注册账号，这一步要你自己完成。
* 各平台都有自己的用户协议。这个插件按正常浏览的方式使用网站，不做批量抓取或自动化刷申请，请你也遵守各平台的规定。
* AI 写的材料仍然需要你读。你的名字在上面。

## 文件夹里会有什么
| 文件 | 用途 |
| --- | --- |
| CLAUDE.md | 总规则，包括你的放权档位和所有长期决定 |
| criteria.md | 找什么岗位、怎么打分、哪些排除 |
| facts_bank.md | 你的经历和数字，所有材料的唯一事实来源 |
| answers.md | 表单常见问题的标准答案 |
| voice.md | 你喜欢的语气，从你的修改里不断更新 |
| tracker.csv | 每个岗位和公司的状态 |
| batch.md | 每天给你审批的清单 |
| jobs/ | 每个岗位一个文件夹：JD 存档、求职信、冷邮件、面试准备 |
